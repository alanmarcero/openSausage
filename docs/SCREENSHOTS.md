# Native UI screenshot

![Released plugin editor](../assets/native-ui.png)

`assets/native-ui.png` was captured on macOS on 2026-10-27 from the actual **v1.1.0 VST3 editor**, loaded in a JUCE 8.0.9 host. It shows the plugin's default state while processing a stereo test signal at 48 kHz with a 120 BPM host transport. The host renders the native AppKit view into a PNG at the display's backing resolution (2320 × 1440). Controls, labels, meters and version text come from the running plugin.
